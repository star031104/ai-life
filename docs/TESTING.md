# 实机测试清单

照顺序做，每一项后面打勾。出问题时记下：时间、做了什么、TA 回了什么、`data/logs/ailife.log` 里对应时间的几行。

## 0. 更新前

- [ ] 关掉正在运行的 start.bat 窗口（同一个 bot 只能有一处在跑）。
- [ ] 备份 `data/` 文件夹（复制一份到别处）。
- [ ] 双击 `selftest.bat`：全部 ✅。版本显示 `8.0（第八批）`。
- [ ] `python run.py persona list`：能看到你的人设和 linxi / shenyan / template，当前是你选的那个，记忆是 `data/ailife.db`。
- [ ] 双击 `start.bat`，日志里出现“<角色名> 上线了”，没有红色报错。

## 1. 原有功能（回归）

- [ ] 普通聊天：分几条发、有停顿、语气对；叫你“哥哥”。
- [ ] `/status`、`/memory`、`/diary`、`/story`、`/goals`、`/people`、`/mind` 都能打开，内容和以前连得上（记忆没丢）。
- [ ] 发语音条 → TA 会说听不了语音、让你打字（语音功能已去掉）。
- [ ] 发图片、贴纸 → TA 能看懂。
- [ ] `/photo` → 能发照片。
- [ ] 小屋网页、桌宠能打开；桌宠不再报 sound 404。
- [ ] 设一个 2 分钟后的提醒 → 到点提醒。
- [ ] 等一段时间不说话 → TA 会主动找你（夜里免打扰时段不会）。

## 2. 读链接（第六项）

每个都发出去，看 TA 是不是真的知道内容（而不是瞎编）：

- [ ] B 站视频链接（`bilibili.com/video/BV…`）→ 说得出标题 / UP 主。
- [ ] b23.tv 短链（B 站 App 里“分享 → 复制链接”）。
- [ ] 只发一个 BV 号。
- [ ] 公众号文章、知乎回答、新闻网页 → 能说出大概内容。
- [ ] YouTube 链接（要开代理）。
- [ ] 打不开的链接（比如要登录的小红书）→ TA 坦白说打不开，不编内容。
- [ ] `http://192.168.1.1` → 不会去访问（日志里写“不是公网地址”）。
- [ ] 如果你的 Clash 是 TUN / fake-ip 模式：普通网页链接也能读。

## 3. 人设工具（给别人用的部分）

在小屋网页“设置 → 人设”里：

- [ ] 能看到人设列表，当前的那个有标记。
- [ ] 打开当前人设编辑，改一句口头禅 → “检查”有结果 → “保存”提示已生效；聊两句能感觉到变化；`data/backup/persona/` 里有备份。
- [ ] 把改动改回去再保存一次。

在 Telegram 里：

- [ ] `/persona` 显示列表；`/persona reload` 正常。

换角色测试（测完要换回来）：

- [ ] `/persona use shenyan` → bot 自动重启，日志里出现“沈言 上线了”。
- [ ] 和沈言聊几句：是男生口吻、把你当女生；`/status` 等系统文字里的“她”变成“他”，但 `/diary` 内容里不乱改。
- [ ] `/persona use <你的人设>` → 换回来，`/memory` 还是原来的记忆（每个角色记忆分开）。

命令行（不用启动 bot）：

- [ ] `python run.py persona check persona/<你的人设>.md` → 没有问题或只有提示。
- [ ] `python run.py persona new` → 回答问题生成一个新文件（可以选让大模型扩写），然后删掉这个测试文件。
- [ ] （可选）下载一张 SillyTavern 角色卡 png，`python run.py persona import 卡.png` → 生成 persona 文件。

## 4. 新用户安装（模拟别人从 GitHub 下载）

在另一个文件夹里（不要在正在用的那份上做）：

- [ ] 解压一份干净的代码（不带 config.yaml、.env、data/）。
- [ ] 双击 `install.bat` → 装完自动进配置向导：填 token、key、代理、选人设。
- [ ] 生成的 `config.yaml` 里没有明文密钥（密钥在 `.env`）。
- [ ] 只做到这里，不要启动（会和你正在用的 bot 抢消息）。测完删掉这个文件夹。

## 5. 手机上

- [ ] 手机 Telegram 里聊天、收照片都正常。
- [ ] 点聊天框左边的“小屋”按钮：能打开，心情、日记、记忆都能看到。
- [ ] 关掉手机 Wi-Fi 用流量：小屋还能打开（走 Cloudflare 隧道）。

## 6. 关机和回来

- [ ] 聊两句后在 start.bat 窗口按 Ctrl+C：手机上收到她一句“先去忙 / 先睡了”。
- [ ] 过 2 小时以上再启动，不发消息：一分半钟左右她主动说这段时间在干嘛（和小屋里她今天的安排对得上）。
- [ ] 关着的时候给她发一句“人呢”，再启动：她回你时顺便说刚才在干嘛，不会另外再发一条。
- [ ] 关机前跟她说“两小时后提醒我交作业”，然后关机超过 8 小时：回来时她会把错过的提醒一起补上。

## 7. 跑一天之后

- [ ] 第二天看 `/diary`：日记写了，没有重复的故事线、目标。
- [ ] `/quality`：重复率、出戏次数正常。
- [ ] 日志里没有反复出现的同一个报错。

有问题带上这份清单和日志片段（`data/logs/ailife.log`，记得删掉私人内容）提 issue。
