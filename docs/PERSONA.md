# 写一个你自己的角色

ai-life 不绑定任何角色。角色就是 `persona/` 里的一个 Markdown 文件：顶部几行基础信息，下面用自然语言写 TA 是谁、什么性格、怎么说话，最后放几段对话示例。

自带三个文件，可以直接用，也可以照着改：

| 文件 | 角色 | 适合 |
| --- | --- | --- |
| `persona/linxi.md` | 林汐，24 岁插画编辑，温柔、有自己的生活 | 默认，女友向 |
| `persona/shenyan.md` | 沈言，27 岁建筑师，稳重、会照顾人 | 男友向（角色是男生、你是女生） |
| `persona/template.md` | 带注释的空白模板 | 从零写 |

## 三种最省事的办法

1. **回答几个问题生成**：`python run.py persona new`
   问名字、性别、年龄、身份、你们的关系、性格关键词、说话风格、爱好，生成一份能直接用的人设。填了大模型 key 的话，还可以让大模型帮你扩写成完整版（补细节和 10 段对话示例）。
2. **导入 SillyTavern / TavernAI 角色卡**：`python run.py persona import 角色卡.png`（也支持 `.json`）
   会把卡里的描述、性格、场景、开场白和示例对话转成人设文件。英文卡建议导入后把正文翻译成中文。
3. **复制模板手写**：把 `persona/template.md` 复制一份改名，按注释填。

写好以后：

```bash
python run.py persona check persona/你的文件.md   # 检查：缺什么、哪里格式错了、正文太长太短
python run.py persona use persona/你的文件.md     # 换成这个角色（重启后生效）
python run.py persona list                       # 看有哪些角色、现在用的是哪个
```

也可以在 QQ 私聊里发 `/persona`，或者在小屋网页的“设置 → 人设”里直接编辑、检查、保存（保存后马上生效，不用重启）。

## 顶部的基础信息

写在文件最上面两行 `---` 之间。只有 `name` 必填，其他都可以不写。

| 字段 | 意思 | 例子 |
| --- | --- | --- |
| `name` | 名字 | `林汐` |
| `call_name` | TA 平时怎么叫你 | `你` / `小满` / `哥哥` |
| `formal_name` | 装正经、闹别扭时的叫法（程序会提醒 TA 别用太多） | `哥哥大人` |
| `user_name` | 在 TA 的世界里你是谁（不写就同 `call_name`） | `学长` |
| `gender` | 角色性别：`female` / `male` / `other` | `male` |
| `user_gender` | 你的性别：`male` / `female` / `other` | `female` |
| `age` | 年龄（必须是成年人，至少 18） | `24` |
| `birthday` | 生日 `MM-DD`，不写就自动挑一个 | `03-15` |
| `identity` | 一句话身份，日程、故事线、长期目标都按它来 | `小出版社的插画编辑` |
| `life` | 怎么过日子：`student`（学期、考试周、寒暑假）/ `worker`（工作日上班、节假日休息）/ `free`（自由安排） | `worker` |
| `work` | 上班时间（`life: worker` 时） | `hours: "10:00-19:00"`、`note: 偶尔加班` |
| `school` | 校历（`life: student` 时，可选，覆盖默认） | `fall_start: "09-01"` |
| `home` | 和你的距离（放假回家时会用到） | `家就在你家隔壁` |
| `look` | 外貌，TA 发自拍时画图用；不写就只拍景物、不画人脸 | `栗色短发，戴细框眼镜……` |
| `catchphrases` | 口头禅（用太多时会提醒 TA 换个说法） | `[嗯, 欸, 哼]` |
| `hold_lines` | 网不好时先说的话（不经过大模型） | `[网卡了，等我一下]` |
| `greeting` | 开场白（导入角色卡时从卡里的开场白取第一行） | `终于等到你了。` |

**性别和代词**：程序内部的说明文字默认用“她”指角色、“他”指你。`gender` / `user_gender` 不是默认值时，会自动告诉模型该用哪个代词；系统提示、小屋网页上的“她”也会换成“他”，生成室友时也会按性别来。

## 正文怎么写

用第二人称写给 TA 看（“你叫林汐，24 岁……”），建议分这几节：

- `# 她是谁`：身份、和你的关系、怎么认识的、现在住哪、平时在忙什么。
- `# 性格`：三到六条。不要只写形容词，写出 TA 会怎么做、怎么说。“温柔”不如“你加班时她不催你回消息，只是等你忙完问一句吃饭了没”。
- `# 说话方式`：口头禅、语气词、开玩笑的方式、生气和认真时怎么说话。保留“短句、分几条发、不用 markdown、不用括号写动作”这一条，像真人发消息。
- `# 底线`：保留模板里的几条（不写露骨内容、不用冷战和愧疚绑住对方、对方说想伤害自己时认真接住并鼓励找人帮忙）。

正文 800～3000 字最合适。免费模型读太长的人设会抓不住重点。

## 对话示例（最影响“像不像”）

写在 `# 对话示例` 下面，6～15 段。每次聊天程序按话题挑 3 段给模型参考，让它学语气和节奏（照抄会被检查出来，要求重写）。

```markdown
# 对话示例

## 他累了 | 累 加班 烦 难过
他：今天加班到九点，好累
林汐：辛苦啦|||先别看手机了，去洗个热水澡|||洗完回来跟我说说今天怎么了
```

- `## 场景名 | 关键词 关键词`：你说的话里出现这些关键词时，优先挑这一段。
- 你说的话用 `他：`（你是女生就写 `她：`，写 `你：` 也行）开头，角色说的话用角色名开头。
- `|||` 表示分成几条消息发。

值得覆盖的场景：打招呼、想念、对方累了或难过、被夸、问在干嘛、深夜催睡、好消息、撒娇、吃醋或小别扭、被问“你是不是 AI”。

## 换角色和记忆

每个角色有自己的一份记忆（聊天记录、日记、身边的人、长期目标……）：

- 第一个用的角色存在 `data/ailife.db`（老用户的数据不会动）；之后新加的角色存在 `data/chars/文件名.db`。
- `persona use` 换过去时默认用这个角色自己的记忆；加 `--share`（或在 QQ 里 `/persona use 文件名 共用`）就沿用现在的记忆。
- 换回原来的角色，原来的记忆都还在。对应关系记在 `data/personas.json`。

只改了人设文件的内容（同一个角色），不用重启：在小屋里保存，或者在 QQ 里发 `/persona reload`。

## 小建议

- 先写对话示例，再写性格。示例比描述更能决定 TA 说话的样子。
- 想让 TA 有自己的生活，就把 `identity` 和 `life` 写准：学生会有考试周和寒暑假，上班族会加班和过周末。
- 写完用 `python run.py eval` 跑一遍评测，看重复率、出戏、回复长度，再按结果调整。
- 请只用你有权使用的设定。基于真实人物、或者照搬别人作品的角色，不要公开分享。
