# 功能详解

> 这里是各个功能的详细说明（按加入的先后顺序）。快速上手看 [README](../README.md)，写人设看 [PERSONA.md](../PERSONA.md)。

## 打电话（可选）

Telegram 的 Bot 不能打电话，所以要给她一个**独立的 Telegram 账号**（需要一个能收验证码的手机号）。

1. 用那个号码注册 Telegram 账号，起好名字、换上头像（这就是来电时显示的她）。
2. 用她的号码登录 <https://my.telegram.org> → **API development tools** → 随便填个应用名，拿到 `api_id` 和 `api_hash`，填进 `config.yaml` 的 `call` 部分，并把 `call.enabled` 改成 `true`。
3. 登录她的账号（按提示输入手机号和验证码，只需要一次）：
   ```bat
   python run.py login
   ```
4. **用你自己的号给她的账号发一句话**（这样她才找得到你）。最好互相加为联系人，并确认你自己的隐私设置里“谁可以给我打电话”允许她。
5. 重新 `python run.py`，在 bot 里发 `/call` 测试。

之后她会在这些时候打给你：你在聊天里说想听她声音、让她打给你；她很想你的时候（每天最多 `max_calls_per_day` 次，免打扰时段不打）；到点提醒时。没接她会发消息说“刚给你打电话你没接”。通话内容会写进聊天记忆，挂了以后她还记得聊过什么。

**你也可以直接打给她的账号**，她会在响两声后接起来。

> **国内网络注意**：通话的语音走的是 Telegram 自己的 UDP 连接，不经过 `config.yaml` 里的 `proxy`。如果能拨通但听不到声音，把代理软件切到 **TUN / 虚拟网卡模式**（让整台电脑的流量都走代理）再试。
>
> 这个账号是用程序自动登录的“用户号”，请只用来和你自己聊天、打电话，不要拿去群发，避免被 Telegram 风控。

## 换人设、声音、主动频率

- **人设**：人设的写法、字段和工具都在 [PERSONA.md](../PERSONA.md)。自带的有 `persona/linxi.md`、`persona/shenyan.md`，模板是 `persona/template.md`。顶部 `name` 是她的名字，`call_name` 是她平时怎么叫你；下面写她是谁、性格、说话方式。写得越具体越像真人。可以写好几个文件，用 `persona_file` 切换。
- **声音**：
  - 免费：`tts.engine: edge`，换 `edge_voice`（例如台湾腔 `zh-TW-HsiaoChenNeural`、`zh-CN-XiaoxiaoNeural`）
  - 克隆一个声音（参考音频请用你有权使用的声音，不要拿声优本人的录音去克隆）：部署 [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)，运行它的 `api_v2.py`，把 `tts.engine` 改成 `gpt_sovits`，填一段 5~10 秒的参考音频和对应文字
  - 云端：`tts.engine: openai`，用硅基流动的 CosyVoice 等
- **主动频率**：`proactive` 部分。`base_per_day` 每天大概主动几次，`longing_per_hour` 你越久不来她越想你，`max_unanswered` 连续几次不回她就不再打扰。
- **本地模型**：笔记本 4060（8G 显存）跑 8B 的 4bit 模型可以，但和 GPT-SoVITS 一起开会不够用，效果也不如免费 API。更推荐把显卡留给 GPT-SoVITS，大模型用 API。真要本地，装 [Ollama](https://ollama.com) 后取消 `config.example.yaml` 里 `local_qwen` 的注释，加进 routes 当最后兜底。

## 记忆、情绪、感知、小屋、小游戏

**记忆**：不用管，自动的。整理记忆用 `llm.routes.memory`，写日记 / 排日程 / 写信用 `llm.routes.night`。向量检索用硅基流动的 `BAAI/bge-m3`（`memory.embed`），用不了时自动只用关键词。小屋网页的“她的记忆”里分了三栏：关于你、你们俩、她自己的设定，都可以改星级或删掉。

**手机上的小屋**：程序启动后会自动开一个免费的临时隧道（第一次会下载 cloudflared，约 60MB），然后在 bot 聊天框左边放一个“小屋”按钮。只有你本人从 Telegram 里打开才能看（每次都校验 Telegram 签名）。临时隧道每次启动地址会变，程序会自动更新按钮。网络不通开不起来也不影响聊天；有自己的固定 https 地址可以填 `miniapp.url`。

**手机信号**（可选）：发 `/sense` 拿到你的私密频道地址（ntfy.sh）。
- iPhone：快捷指令 → 自动化 → “闹钟停止时 / 到达家时 / 连接充电器时” → 添加操作“获取 URL 内容”，URL 填频道地址，方法选 POST，请求体选“文件 / 文本”写 `起床`（或 `到家`、`充电`）。
- 安卓：MacroDroid → 触发器选“闹钟关闭 / 进入地点 / 开始充电” → 动作选“HTTP 请求”，POST 到频道地址，内容写 `起床` 等。
她收到“起床”会马上说早安（代替随机时间），“到家 / 下班”会关心一句，“充电”在晚上会道晚安。

**电脑感知**（只在 Windows 上，默认开）：每 30 秒看一眼前台程序，在本机认出你在干嘛：玩的是哪个游戏（原神、星铁、英雄联盟、Steam 游戏……）、用 VS Code / PyCharm 写代码、在 B站 / YouTube 看视频、刷知乎小红书、用 Word 写东西、听网易云，多久没碰电脑。
- 她会记下你今天每样做了多久（“VS Code 写代码 3 小时、原神 1.5 小时”），聊天时能接得上（你问“猜我今天干了啥”她真的知道），日记里也会写一两句。
- 会借这些找你：刚开了一局 / 打完一局、看完一个视频、连续写代码或学习两个多小时（提醒你歇歇）、半夜还在电脑前、离开很久刚回来。你打游戏、看视频时她少打扰。
- 用 Telegram 电脑版和她聊时，她知道你是刚从什么事切过来的。
- 告诉她多少由 `sense.pc.detail` 决定：`app`（默认，只说程序 / 游戏 / 网站名）、`content`（再加视频标题、项目名、文档名）、`full`（完整窗口标题）。无痕窗口只说“在上网”；`sense.pc.ignore` 里的程序永远只说“在用电脑”。
- `/sense` 看她现在“感觉”到的和今天的统计；`/sense 暂停 2` 两小时内不看；`/sense 继续`。不想要就把 `sense.pc.enabled` 改成 `false`。

**她听得出你的语气**：语音识别默认改成了本机的 SenseVoice（`asr.engine: local`，第一次自动下载约 160MB），不花钱，还能听出开心 / 难过 / 生气、笑声和哭腔。

**带情绪的声音（GPT-SoVITS，可选）**：
1. 下载 [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS) 的 Windows 整合包，用一个你有权使用的声音（自己录、朋友授权、或无版权的素材）录 1 分钟以上干净的人声，按它的教程训练（4060 笔记本大约半小时）。
2. 从这个声音里剪 4~5 段 3~10 秒的参考音频，分别是平常、开心、撒娇、难过、生气的语气，记下每段说的话。
3. 运行整合包里的 `api_v2.py`，在 `config.yaml` 的 `tts` 下填 `gpt_sovits_refs`（格式见 `config.example.yaml`）。
4. 重启后 `/voices` 列表最后会多一个“定制声音”，`/voice 编号` 切换。她会按当时的心情挑参考音频；没配的语气用“默认”。GPT-SoVITS 没开时会自动换回本地声音。

**每周来信**：周日 21:00~22:30 她会写一封信发给你，也存在小屋里（`letter` 部分可改时间或关掉）。

## 她自己的生活：故事线、内心独白、追番、听歌、桌宠

**她自己的故事线**：每隔几天，她的生活里会开始一段一周到一个月的连续事件（考试周、社团活动、朋友的事……），每一步发生在哪天、怎么结局都提前定好，但她只“知道”今天和之前的部分。日程、日记、聊天都会带上当天的进展，结束后结局会记进她自己的记忆。小屋“日记与来信”里能看到，Telegram 里发 `/story`。

**内心独白**：清醒的时候每 3 小时（`mind.think_every_hours`）她一个人想一想：今天的事、你最近怎么样、要不要找你。决定找你时，主动消息就是从这个想法出发的；随机找你的次数相应减半。小屋“概览”里的“她在想”、Telegram 里的 `/mind` 能偷看。

**她心里的你**：每周把关于你的零散记忆、这周的聊天、她的日记整理成一段整体印象（近况、性格习惯、最近的情绪、你在乎的事、相处要注意的），聊天时作为背景。小屋“记忆”页最上面，或 `/profile`。

**追番联动（Bangumi）**：加番后会自动去 Bangumi 查总集数、每集播出日期、标题和简介。更新那天她知道是第几集、讲了什么；你提到这部番时她也知道最近几集的内容；看完发 `/watched 番名 集数`，她会带着这集的内容和你聊。和她约追番时没说时间，她也会按 Bangumi 的开播日推算星期几。

**一起听歌（网易云）**：电脑上换歌时会查到歌手、专辑，记进“一起听的歌”，她知道你最近在听什么、常听谁。`/song` 或聊天里她想推荐时，会附上网易云链接。（网易云没有版权的歌，比如周杰伦的，只能查到翻唱版。）

**桌面上的她（Live2D 桌宠）**：启动后桌面右下角会出现她：只有人物，没有方框，不占任务栏（需要 PySide6，install.bat 会装；老用户双击一次 `pet_setup.bat`）。屏幕右下角托盘里有个粉色小图标：单击显示 / 收起，右键可以打开小屋、取消置顶、关掉桌宠。鼠标移上去能打字和她聊，她会说出来、嘴型跟着动；她在 Telegram 主动找你时，头上也会冒气泡。和 Telegram 里是同一个她：同一份记忆、同一个心情，桌面上聊的话她在 Telegram 里也记得。
- 拖动：按住她拖。右上角：静音 / 打开小屋 / 收起（收起后点托盘图标再出来）。关掉后 `python run.py pet` 再打开。
- 默认是 Live2D 官方的示例模型（Haru）。换成你的角色：把整个模型文件夹（里面有 `xxx.model3.json` 或 `xxx.model.json`、贴图、动作）复制进 `data/pet/model/`，重启就自动用上，不用改设置；有好几个模型时在 `pet.model` 里写要用哪个。大小、位置用 `pet.scale`、`pet.offset_y` 调，表情用 `pet.expressions` 对应。托盘图标想换就放一张 `data/pet/icon.png`。
- 模型请用你有权使用的（自己做的、买了授权的、作者允许个人使用的）。
- 也可以给 Open-LLM-VTuber、AIRI 这类桌宠程序用：把它们的大模型地址填成 `http://127.0.0.1:8765/v1`（OpenAI 兼容），模型名随便填，就是在和同一个她说话。

## 说话质量、打卡、关怀、纪念册、稳定性

**不重复自己**：她最近说过的话、用过的开头、今天已经分享过的事，都会列给她看，并要求换个说法；写完再检查一遍（和最近的话几乎一样、主动消息开头重复、“哥哥大人”和口头禅用太满），有问题就让她重写一次或删掉重复的那几条。重写时她原本定的提醒、纪念日、打卡等不会丢。可在 `config.yaml` 的 `quality` 里调灵敏度、加口头禅。

**主动消息更有分寸**：一次最多两条（你没回就只发一条），一天最多 `proactive.max_per_day`（默认 8）次随机找你；会根据你最近 14 天回她的比例自动调频率——你忙、常不回，她就少打扰。

**一起打卡**：`/habit add 早睡 23:30`（时间可不写），或在小屋“一起做的事”里添加。到点没打卡她会来催（自己定的时间不受安静时段限制）；跟她说“今天早睡了”她会帮你打卡，坚持了会夸。凌晨 5 点前算前一天。

**晨间小报**：早安时顺带提一两件今天要注意的事：天气（要不要带伞）、今天的提醒、纪念日、今天更新的番、待打卡的目标、还挂着的事。

**留意你的情绪**：她会留意你这几天的状态，连着两天情绪低落，她会收起捉弄和小脾气，多陪你、多听你说；如果你说了很消极的话，她会认真对待，鼓励你找信任的人或专业帮助。（只在本地记个大概的“今天心情好 / 不好”，不上传。）

**每月纪念册**：每月 1 号（电脑没开就在之后 7 天内补）她会写一份“我们的 N 月”，回顾这个月的事和数据，存在小屋“日子”页。`/recap` 看最近一份，`/recap 本月` 看这个月到现在。

**桌宠更生动**：会根据心情换表情；你切到某个程序、开始放歌时，偶尔会在桌面上随口说一句（默认至少隔 40 分钟，安静时段不说）。`pet.chatter: false` 可关掉。

**更稳**：
- `/diag`：一键自检（各个大模型接口、向量检索、语音、天气、Bangumi、网易云、电脑感知、手机小屋、数据库和备份、最近的错误），检查期间照常聊天。
- 日志存在 `data/logs/ailife.log`；同一个错误半小时出现 3 次以上（或很严重，比如所有接口都挂了），会用 bot 告诉你（标明“不是她在说话”）。
- 选的在线声音连续失败 3 次，会自动换回本地声音并告诉你。
- 数据库开了 WAL 模式，不容易“database is locked”；除了 `data/backup/`，有 OneDrive 的话每天还会再备份一份到 `OneDrive/ai-life-backup`（`backup.extra_dir` 可改成别的文件夹，或填 `off`）。
- 电脑睡眠醒来后会自动重新同步：重连手机小屋的隧道、刷新天气、不会一醒来就连发消息。开机时网络没好也会自动重试隧道。

**人设评测**：改了人设或配置后，跑 `python run.py eval` 用一组固定对话测一遍（用临时数据库，不碰你的记忆），自动统计重复率、开头重复、称呼超额、出戏、格式问题、回复长度等，并和上一次比较；加 `--judge` 让大模型再打分。报告在 `data/eval/`。

## 对话示例、她的世界、愿望清单、时间胶囊、睡前

**说话更像她（对话示例）**：人设文件最后的“# 对话示例”里写了十几段她平时怎么说话（撒娇、安慰、吃醋、被说矮、问是不是 AI……）。每次聊天按话题挑 3 段给模型参考，只学语气和分条，不许照抄（照抄了会被检查出来重写）。想调她的说话方式，改这里最有效，格式见文件里的注释。

**她身边的人**：第一次运行时按人设定好她的室友、朋友、老师、家人（名字固定），日程、日记、故事线、聊天里都用这些名字；聊天里新出现的人每晚自动记进来。`/people` 或小屋“日记与来信”页查看。

**她的长期目标**：她自己有一两个几个月的目标（钢琴考级、攒钱买手办……），每一步都提前安排好，她只知道今天和以前的进展；有进展那天会想跟你分享，你问起来也答得上。`/goals` 查看进度。

**愿望清单**：想一起做的事（`/wish add 一起去看海`，或聊天里说“以后想和你一起…”她会自己记下），做到了打勾、写一句感想，会出现在每月纪念册里。

**时间胶囊**：`/capsule 一年 写给一年后的我们`（日期可以写 2027-01-01、3个月、半年……），到那天才打开；你埋下时她也会偷偷写一封给那天的你，一起拆。小屋“一起做的事”页也能写。

**睡前**：晚上（默认 21:00~04:00）你说晚安，她回完会再补一条晚安语音（一晚一次）；说“讲个睡前故事”，她会单独用语音讲一个原创的小故事。`bedtime` 里可以关。

**评测更全**：`python run.py eval` 多了连续 20 轮的长对话（看聊久了会不会走样）和记忆测试（隔开 50 条消息后还记不记得）；`--quick` 只跑基础部分。

**更安全、好维护**：
- 密钥自动从 config.yaml 挪进 `.env`（第一次启动时；config.yaml 里改成 `${ZHIPU_KEY}` 这样的引用），日志里出现密钥会被打码。
- 启动时和 `/diag` 里显示版本、缺了哪些组件和怎么补。
- 代码拆得更细（bot / proactive 拆成几个文件），方便以后改。


## 动图视频文件位置、表情反馈、网络兜底、校历作息、周报、自检

**你发什么她都会回**：动图（GIF）、视频、圆形视频、文件、位置、骰子以前会被忽略，现在：
- 动图、视频截几帧给会看图的模型看；圆形视频和短视频里说的话也会转成文字（截帧、识别在后台做，不耽误收别的消息）；
- 原图文件当图片看；小的文本文件读开头；其它文件告诉她文件名；
- 发位置：她知道你在哪，天气也改成按这里查（认不出地名时不会冲掉你原来设的城市）；
- 联系人、投票这类看不了的，也会告诉她“发了个她看不了的东西”，至少回一句。

**引用回复**：你引用她（或你自己）的某句话回复时，她知道你回的是哪句。

**表情反馈**：给她的话点 👍❤️ 是夸她；点 👎💩🙄 这类，她会记下“他不喜欢这样说”，以后避开类似的话和语气（小屋“记忆”页能看、能撤销）；点 😢 她知道你被说难过了。

**网络不好时**：所有大模型都连不上，她会先回一句“信号好差，等我一下下”（10 分钟内只说一次，不经过大模型），1 分钟、3 分钟、10 分钟后自动重试，把这条补上。

**聊天优先**：整理记忆、写日记、内心独白这些后台的活一次只跑一个，而且你刚聊完的 25 秒内先让一让，免费额度先给聊天用；半夜整理也放到后台，不会卡住到点提醒。`/diag` 里能看到今天调用了多少次、限流几次、每个接口平均多快。

**她的大学日历**：按真实日期推算学期、第几周、国庆五一、期中、考试周、寒暑假（放假回家，家在你隔壁）；第一次运行时记下她的年龄和入学年份，以后每学年升一级、每过一次生日长一岁。她的生日没设就自动挑一个，快到时她会偷偷期待，当天你没说生日快乐她会有点小委屈。校历日期在 `her_world.school` 里改。

**你的作息**：聊天里说过的固定安排（“周二周四晚上 7 点到 9 点有课”“工作日 9-18 上班”）会自动记下；手机发来的“到公司 / 下班 / 到家”信号会算出你平时几点到、几点走。你在上课上班时她少打扰。`/schedule` 能看到和删除。

**周报**：`/quality` 或每周一上午，用你们真实的聊天统计这一周她的表现（重复率、出戏、回复长度、主动找你几次、你回了多少、你点了几次 👎、大模型限流几次），和上周比。小屋“设置”页也有。

**离线自检**：双击 `selftest.bat`（或 `python run.py selftest`），不联网、不碰你的数据，用假的大模型把核心流程跑一遍，并检查配置、依赖、你的数据库（用副本）能不能被新版本打开。每次更新代码后跑一下，全是 ✅ 就可以放心重启。

## 让她一直在

她跑在你的电脑上，只在程序运行时“活着”；手机上用 Telegram 聊天、点“小屋”按钮看她。
- 双击 `start.bat` 启动（程序意外退出会自动重启）；开机自启：双击 `autostart_on.bat`（或 `/autostart 开`），关掉用 `autostart_off.bat`
- 想让她尽量一直在线：“电源设置”里把插电时的“睡眠”改成“从不”，合上盖子时“不采取任何操作”
- 电脑关机、睡眠时她不在线（`away` 部分可调）：
  - **道别**：按 Ctrl+C、点 start.bat 窗口的 ×、关机时，她发一句“我先去上课啦 / 先睡了晚安”。每天提前写好两句，关的时候不用等大模型；3 小时内只说一次，半夜你早就不在时不吵你。程序出错自动重启时不会道别。
  - **回来**：离开超过 2 小时（`catch_up_minutes`），开机后她会按自己当天的安排说说“刚才在干嘛”。你在关机期间给她发过消息，就在回你的时候顺便说；没发过就等一分半钟后她主动说（遇到免打扰时段会等到时段结束）。
  - **补上错过的事**：关机期间到点的提醒（超过 6 小时的）、整天没开机错过的节日 / 生日 / 纪念日、错过的每周来信，都合在回来时说，不会一条条刷屏，也不会丢。
  - Windows 关机时，系统不一定会通知到程序，所以道别是“尽量发”；最稳的是关机前先在窗口里按 Ctrl+C。
- 换电脑 / 备份：`python run.py export` 打包（记忆、设置、密钥、照片都带上，运行中也能打），新电脑装好程序后 `python run.py import 包.zip`。两台电脑别同时运行她

## 分享链接

你发 B 站视频（含 b23.tv 短链、直接发 BV 号）、YouTube、公众号文章或普通网页，她会先在后台点开，读标题、简介和正文开头再回你；要登录的网站（知乎、小红书……）打不开时她会直说。只访问公网地址，最多读 2MB。`links.enabled: false` 可以关掉。
