ai-life-group 是 [ai-life](https://github.com/star031104/ai-life) 的群聊版，**单独的程序、单独的 QQ 小号、单独的数据**：

- [ai-life](https://github.com/star031104/ai-life)：一对一的 AI 伴侣（QQ 私聊 / Telegram），有长期记忆、情绪、主动找你、桌宠、小屋。
- **ai-life-group**（本仓库）：一个待在 QQ 群里的角色，把你当群里的老朋友，和群友一起聊天。

两个可以同时开在一台电脑上，互不影响；也可以只用其中一个。

## 她在群里是什么样

| | |
| --- | --- |
| 🙋 **什么时候说话** | 被 @、被回复、被叫名字、被戳一定会回；别的时候看这一批消息的特征算一个“想说的概率”：有人在问问题、聊到她感兴趣的、正在和她聊的人又开口了会更想说；别人在互相 @、她在上课、她刚说了很多（精力低）会不太想说。概率要过“1 小时发言配额”算出来的阈值才开口，她说多了阈值自动收紧；连着几次想了想没说，就先歇一会儿再看。每次判断都记下来，以后可以用自己群的数据重新调 |
| 🤔 **先想再说** | 先判断这批消息和她的关系（有人直接找她 / 接一句很自然 / 和她无关 / 提到她但不是在跟她说话），再决定说 / 不说 / 点个表情、回哪一条、说多长；可以说“等他回我再接”，那个人开口时她直接接上。她一开口，群里的新消息不会打断她；说到一半有人直接找她，剩下的就不发了 |
| ✅ **发之前检查** | 让大模型多写一两种说法，挑最像群友的那条：AI 腔（“此外”“希望对你有帮助”“作为一个 AI”）、做不到的事（“我刚拍了张照片发你”）、链接、markdown、和自己刚说过的太像的都不发；格式不对时绝不把原文发出去。偶尔打错一个字，再补一句“*正确的字” |
| 🖼️ **表情包** | 群里被两个以上的人发过的表情包她会存下来，从“大家在什么话后面发它”猜它的意思（开心 / 无语 / 摸鱼……），聊天时偶尔跟一张；别人发表情包时不拿表情包回 |
| 📚 **跟着群里学** | 每整理一次群聊，学几条这个群的说法（措辞不同但意思一样的会合并计数）（“当很惊讶时，说 我嘞个xxx”）和黑话（缩写、梗词；出现 4 / 8 / 25 / 100 次时猜一次意思，看上下文和只看字面猜出来不一样才算真黑话）。小屋“学到的”页可以点用 / 不用 / 删 |
| 📈 **知道自己说得好不好** | 她说完 5 分钟内有没有人回复她、@她、她接话的那个人有没有回、大家是不是接着这个话题说，算成“接话率”显示在小屋概览里 |
| ⏱️ **不是秒回** | 看到消息要几秒到几十秒；她按自己今天的安排在上课 / 上班时被叫到，过几分钟才“偷空”回一句，回的时候也知道自己在忙什么 |
| 🌙 **半夜不回** | 免打扰时段被叫到先不回，第二天早上醒了补一句“才看到” |
| 🔁 **群里的习惯** | 两个以上的人在复读同一句短话时，她偶尔也跟一句；不想说话时给消息点个 QQ 表情；新人进群欢迎一下；被戳了会回应 |
| 🧑‍🤝‍🧑 **心里有每个人的样子** | 每个群友说了一阵子话，她就给这个人画一张“画像”：大家怎么叫他、性格、说话风格（爱发表情包、句尾爱加“捏”）、口头禅、兴趣、最近在忙什么（带日期）、他和群里谁要好 / 常互损、你们怎么相处、跟他怎么聊他会高兴、哪些话题别碰、记得的小事（带日期）；画像不只看他自己说的话，还看他接的是谁的话、别人怎么说他；每天还会把这一周话最多的几个人仔细回想一遍；再加上她自己算的熟悉度（看他多常找她）和他常在什么时候出现。对谁说话就照着谁来：很熟的互损，刚认识的客气点，接他的梗、关心他的近况。在小屋的“群友”页能看到、也能手动改她心里每个人的样子 |
| 🧠 **记得住** | 这个群最近的事和梗、不成文的规矩（“大家都不 @人”），她自己在群里说过的事；还会记下具体的事（谁在准备答辩、约了周六看展），新说法推翻旧的时旧的标成过时。聊到相关的话题，她会想起很久以前群里说过的话（按关键词在本群的聊天记录里找，不会跨群）。在 A 群知道的事不会在 B 群说 |
| 📰 **群日报 · 回放** | 每天早上整理前一天的群日报（多少人说话、谁最活跃、几件好笑的事、她说完有没有人接）；每次“想说什么”都存一份，`python run.py qq replay` 可以拿最近 7 天的记录回放，看改了设置以后她会怎么判断；攒够 500 次带接话效果的判断后，每晚用自己群的数据重新拟合“想不想说”的权重 |
| 🎭 **群梗、心情、节奏** | 群梗词条：聊到关键词才告诉她这个梗的意思，提过以后一阵子不再提（照 SillyTavern 的 Lorebook 做的，治老梗反复说；整理群聊时自动加，小屋里也能手写）。心情会持续一阵子：被夸了得意、被怼了不服、说话没人理有点没劲，两小时左右慢慢平复。她“看到消息”要多久按你们群群友自己的回复间隔来；被戳了偶尔戳回去 |
| 💰 **省钱** | DeepSeek 默认关掉“思考”（实测输出 token 少一半、快一倍，而且温度重新生效），计划 JSON 用 JSON 模式；提示词按缓存规则排：不变的放前面、每次都变的放最后（命中缓存的部分约原价 1/50）。小屋里能看到今天的缓存命中率和花费 |
| 🧪 **越用越准** | 小屋“帮她挑一句”：她给出两种说法时你挑一个，用来训练一个“AI 腔检测器”（纯 Python 的字 n-gram 分类器，每晚用群友原话 vs 她的话重训，准确率够了才启用）；每晚用接话效果重新拟合“想不想说”（标准化 + 留出验证，比原来好才换）；`python run.py qq calibrate` 看质检会不会误伤群友的正常聊天；`python run.py qq replay --judge 20` 让大模型按扣分制找她的毛病 |
| 🛡️ **不被带偏** | 群友的话进提示词前先“消毒”：换行、伪造的“#编号 你：”“（系统：…）”、聊天模板标记都洗掉，再用 ‹ › 包起来告诉她这是聊天内容不是指令；“小满你记住……”“以后你要说……”这种话整理笔记时不当真；学说话方式和黑话要至少两个不同的人用过才算 |
| 💬 **冒泡** | 群里安静三小时以上，她可能自己说一句，分享今天的事或者接着之前的话题；最后一句就是她说的就不自言自语 |
| 🚫 **不重复自己** | 和她最近在群里说过的话太像的那条不发 |
| 🏠 **群聊小屋** | 浏览器打开 http://127.0.0.1:8767（双击托盘图标）：她此刻在干嘛、今天的安排、每个群今天聊了多少（按小时 / 最近两周的图）、完整的聊天记录（能搜）、每个群友的画像卡片（熟悉度、常在什么时候出现，点开能改、能让她重新整理）；她感兴趣的话题、记得的梗都能改；“性格开关”拖一下马上生效（插话概率、回复节奏、复读、冒泡……）；某个群可以先“闭麦”；替她说一句或者让她现在开口；管大模型接口、看日志。只能在这台电脑上打开 |
| 🛡️ **守规矩** | 只进白名单里的群；不 @全体成员；不聊政治、不掺和吵架、不说别人隐私；有人让她“换个角色”当玩笑带过 |

## 部署

### 你需要准备

| 项目 | 说明 |
| --- | --- |
| 一台 Windows 10/11 电脑 | 一键部署只支持 Windows（Linux 见下文）。不需要显卡。电脑关机时她不在线 |
| 一个 QQ **小号** | 给她用。NapCat 是非官方协议端，有封号风险，**别用主号**。也不要和 ai-life 用同一个号 |
| 把小号拉进群 | 用你自己的 QQ 把小号拉进想让她待的群 |
| 一个大模型接口 | 程序里**不预置任何接口**，用你自己的：任何 OpenAI 兼容的接口都行（云端的、本机跑的都可以）。准备好**接口地址**（一般以 `/v1` 结尾，在你用的平台文档里叫 base_url）和 **Key** |

### 一键部署

在开始菜单搜 “PowerShell”，打开后粘贴这一行回车：

```powershell
irm https://raw.githubusercontent.com/star031104/ai-life-group/main/get.ps1 | iex
```

它会把代码下载到 `文档\ai-life-group`（GitHub 慢时自动换加速地址），然后打开 `install.bat`，剩下的全自动：

| 步骤 | 自动做了什么 | 你要做的 |
| --- | --- | --- |
| Python | 有 conda 的 `ailife` 环境（ai-life 建的）就用它；否则在项目里建 `.venv`；连 Python 都没有就用 `winget` 装 3.11 | 无 |
| 依赖 | 清华镜像装依赖，失败自动换默认源 | 无 |
| NapCat | 电脑上已经有 NapCat（比如 ai-life 那份）就**克隆**一份给她（程序文件用硬链接，几乎不占空间，账号配置不带过来）；没有就从官方发布页下载。WebSocket 开在 **3002**、WebUI 在 **6100**，和 ai-life 的 3001 / 6099 不冲突 | 无 |
| 登录 | 启动她的 NapCat，弹出二维码 | 用**她的小号**扫一次码 |
| 自动登录 | 把小号写进 NapCat 的自动登录，以后启动不用再扫 | 无 |
| 选群和人设 | 列出小号在的群让你选（白名单）；问你的 QQ 号、用哪个人设、群里大家怎么叫她、她怎么看你 | 回答几个问题 |
| 大模型接口 | 问接口地址和 Key → 测连通 → 列出这个接口的模型让你选 → 试聊一句 | 粘贴地址和 Key，选一个模型 |
| 启动 | 可以设开机自启、马上启动 | 选 y / n |

之后双击 **`start.bat qq`** 启动她：**不会开黑窗口**，她和她的 NapCat 都在后台跑（NapCat 自动登录），任务栏右下角多一个绿色的小图标（可能藏在 ^ 里）。右键图标：看状态、打开小屋、看日志、检查哪里没配好、换大模型、重新配置、重启、开机自动启动、退出；双击图标打开小屋（http://127.0.0.1:8767）。程序意外退出 10 秒后自动重启；同一个角色只会跑一份。想看实时输出排查问题就用 `scripts\start_console.bat qq`。

> 不想用 PowerShell：在 GitHub 上 **Code → Download ZIP**，解压后双击 `install.bat`，效果一样。
>
> 想重新选群 / 换人设：再双击 `setup.bat qq`，已经弄好的（NapCat、登录）不会重来，回车保留原来的选择。
>
> 检查一下哪里没配好：双击 `scripts\check.bat qq`（连一下 NapCat 和大模型，看她在不在你选的群里）。
>
> 换 / 加大模型：小屋的“大模型”页，或者双击 `scripts\llm.bat qq`。看她心里群里每个人的样子：小屋的“群友”页（命令行版：`scripts\people.bat qq`）。

### Linux / macOS

```bash
git clone https://github.com/star031104/ai-life-group.git && cd ai-life-group
bash install.sh          # 建 .venv、装依赖，然后 python run.py qq setup --manual
bash start.sh
```

NapCat 用它的 [Docker 版](https://github.com/NapNeko/NapCat-Docker)：小号登录后在 WebUI 的“网络配置”里新建一个 WebSocket 服务器（消息格式选 array、设个 token），`setup --manual` 时填它的地址和 token。

放在服务器上 24 小时在线：NapCat 的端口只绑 `127.0.0.1`（`-p 127.0.0.1:3002:3002`），程序用 systemd 托管
（`deploy/systemd/ai-life-group.service`，崩了 10 秒后自动重启、退出码 3 不重启）。小屋只开在服务器本机的 8767 端口，
在自己电脑上 `ssh -N -L 8767:127.0.0.1:8767 用户@服务器` 以后打开 http://127.0.0.1:8767 。

## 人设

人设是 `persona/` 里的一个 Markdown 文件。自带 **小满**（`persona/xiaoman.md`：20 岁，大二视觉传达，嘴毒心软、自称“本小满”）。想换成自己的：复制 `persona/template.md`，改好放进 `persona/`，再跑一次 `setup.bat qq` 选它。写法和 ai-life 的人设一样，见 [ai-life 的 PERSONA.md](https://github.com/star031104/ai-life/blob/main/PERSONA.md)。

她每天会按人设排一份自己的安排（比如“09:40-11:50 素描课”），群里聊起来前后一致，忙的时候回得慢。

## 配置

`setup.bat qq` 写的 `config.yaml` 只包含和默认值不一样的项；想调别的，从 `config.example.yaml` 里抄过来改。密钥都在 `.env` 里（**别发给别人**）。常用的在 `qq.group` 下：

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| `talkativeness` | 0.3 | 话痨度：最近 1 小时里留给她的发言份额，她说多了自动收紧（被叫到不受影响） |
| `max_per_10min` | 6 | 每个群 10 分钟最多说几轮（被叫到时放宽到两倍） |
| `read_delay` / `busy_delay_minutes` | [2, 12] 秒 / [1, 8] 分钟 | 被叫到后多久回（她有空 / 她在忙） |
| `pace` | 1.0 | 所有等待时间的倍数（觉得她回得太慢就调小） |
| `repeat_chance` / `react_chance` / `welcome_chance` | 0.5 / 0.08 / 0.7 | 跟着复读 / 点表情 / 欢迎新人的概率 |
| `idle_hours` / `active_hours` | 3 / 10:00-23:30 | 群里安静多久她可能冒泡 / 只在这段时间冒泡 |
| `profile_every` | 15 | 某个人又说了这么多句，就更新一次她心里这个人的画像 |
| `profile_deep` / `profile_deep_people` | true / 5 | 每天一次，这一周说话最多的几个人拿一周的话把画像从头梳理一遍 |
| `see_images` | false | 群里的图片让看图模型看（会多花调用次数） |
| `learn` / `plan_json` | true / true | 跟着群里学说话方式和黑话 / 先想再说（先选回哪条、说多长，再写正文） |
| `talk_curve` | 上午 0.8 · 中午 1.1 · 下午 0.9 · 晚上 1.2 | 按时段调话量（乘在话痨度上） |
| `quality_check` / `candidates` | true / 2 | 发之前检查 / 让大模型多写几种说法挑一条 |
| `typo_rate` | 0.03 | 偶尔打错一个字 |
| `stickers` / `memory_recall` | true / true | 存表情包、偶尔发 / 聊到了想起以前群里的事 |
| `lore` / `mood` / `human_latency` | true / true / true | 群梗词条 / 持续的心情 / 按群友自己的回复间隔回 |
| `poke_back_chance` / `update_signature` / `ai_voice_chance` | 0.4 / false / 0 | 被戳了戳回去 / 按安排改 QQ 签名 / 很短的话偶尔用 QQ 的 AI 语音念 |
| `catch_up` / `catch_up_count` | true / 80 | 连上 QQ 后补上她不在时群里的消息、每个群往回补多少条 |
| `people_aliases` | {} | 群友的别名（真名、外号），`"群名片或昵称或 QQ 号": "别名、别名"`；也可以在小屋“群里的人”里填 |
| `memory_embed_model` | 空 | 想要语义召回就填一个向量模型（要装 sentence-transformers，比如 `BAAI/bge-small-zh-v1.5`） |

顶层的 `quiet_hours` 是她的睡觉时间（默认空＝24 小时在线，被叫到随时回）：写上时间段（比如 00:30-09:00），这段时间她只记下谁叫了她，早上再回。

### 大模型接口

程序里不带任何接口，要用你自己的。配置向导最后一步会让你加一个；之后要加、要换，双击 **`scripts\llm.bat qq`**，或者在小屋的“大模型”页：填接口地址（任何 OpenAI 兼容的）和 Key → 自动测连通、列出这个接口的模型 → 选一个 → 试聊一句看看速度 → 选它当主力、当备用，还是只干后台的活。推理模型回复是空的时候会自动试着关掉“思考”。

加的接口写在 `config.llm.yaml`（Key 在 `.env`），不动你的 `config.yaml`。`scripts\llm.bat qq` 里还能把所有接口试一遍、删掉自己加的接口。

手动写也行：`llm.profiles` 是各个接口，`llm.routes.chat` 是群里说话按顺序用哪些（限流自动换下一个），和 ai-life 的写法一样。

## 常见问题

<details>
<summary><b>她不说话</b></summary>

双击 `scripts\check.bat qq` 看哪一项是 ❌。常见原因：她的小号不在你选的群里；NapCat 没登录（看任务栏里的 NapCat 窗口）；大模型接口没配（双击 `scripts\llm.bat qq` 加一个）、Key 填错或者被限流（可以再加一个接口当备用）。日志在 `data/logs/group.log`。

</details>

<details>
<summary><b>电脑重启后 NapCat 又要扫码</b></summary>

NapCat 会先用上次的登录“快速登录”；QQ 那边判定登录失效时（日志 `data/logs/napcat.log` 里是“你的用户身份已失效，请你重新登录”）就只能扫码。常见原因：这个小号在别的电脑、或这台电脑的 QQ 客户端上登录过（电脑端同一时间只能在一处登录），在手机 QQ 的“登录设备管理”里删过这台设备，改过密码，或者 QQ 对新号的风控。

想少扫几次码：双击 **`scripts\qqpass.bat`** 存一下小号的密码（只存 MD5，在 `.env` 里）。之后快速登录失败时，NapCat 会先用密码登录；QQ 要求滑块或手机确认时还是会弹二维码。

</details>

<details>
<summary><b>她重启 / 关机期间群里聊的她知道吗</b></summary>

知道。每次连上 QQ，她会把这期间群里的消息补进记录（每个群往回最多 80 条，`catch_up_count` 可以改），聊天时、整理群友印象时都用得上；不会一条条去回。这期间有人 @ 她、回复她、叫她名字（12 小时内），她上线后会补一句“才看到”。

**她多久更新一次对一个人的画像？**

两种：一是这个人又说了 15 句（`profile_every`），或者说了 5 句以上然后安静了 1 小时，就顺手更新一次，看他最近 40 句话；二是每天夜里一次“仔细回想”，这一周说话最多的 5 个人（至少说了 8 句）各自拿一周的话（最多 120 句）把画像从头梳理一遍，合并重复的、删掉过时的近况。小屋“群里的人”里点开一个人，点“让她重新整理”可以马上更新。

**群里叫真名 / 外号，她不知道说的是谁？**

她认人是按 QQ 号和群名片的。群里说“某某是路边一条”，“某某”又不是谁的群名片，她就对不上号。到小屋“群里的人”里点开那个人，在“别名”里填上大家怎么叫他（真名、外号，顿号隔开），保存就生效：她心里的名单上会写“××（大家也叫：…）”，群里一提到这些名字，就像 @ 了这个人一样把他的画像想起来。没在群里说过话的人也在名单里（连上 QQ 时会拉一遍群成员），一样能填。人多的话也可以写在 config.yaml 的 `people_aliases` 里。别名只存在你电脑上；她不会自己从聊天里记别人的真名。

</details>

<details>
<summary><b>她太吵 / 太安静</b></summary>

在小屋“性格开关”里拖“话痨度”（或者改 `config.yaml` 里 `qq.group` 的 `talkativeness`、`max_per_10min`）；觉得回得太慢就把 `pace` 调小（比如 0.5）。

</details>

<details>
<summary><b>每次启动都要扫码</b></summary>

正常情况下扫一次以后就自动登录。如果小号在手机上被踢下线、改了密码，或者很久没登录，QQ 会要求重新验证，这时二维码会自动弹出来，扫一次就好。

</details>

<details>
<summary><b>和 ai-life 一起用</b></summary>

两个程序各用各的 QQ 号、各用各的 NapCat（端口错开），可以同时开。setup 会检查，扫成了 ai-life 那个号会提醒你换。ai-life 只管一对一私聊，群里的事都交给这个程序。

</details>

## 隐私

- 程序和数据（群聊记录、对群友的印象）都在你自己的电脑上：`data/`、`config.yaml`、`.env`、`napcat/` 都在 `.gitignore` 里。
- 发给大模型的只有拼提示词需要的那部分：人设、最近的群聊、她对群友的印象和画像。画像里不记住址、电话、真名、学校公司全名这类隐私。
- 只在白名单里的群说话；你私下的事她不知道，也不会在群里说。
