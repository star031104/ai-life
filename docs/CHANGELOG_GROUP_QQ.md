# 更新记录

## 4.4.0 — 会看视频、知道大家在哪
- **B 站视频真的“看”了**（`aigroup/net/bili.py`）：群友发 B 站视频，她后台“看”一遍——字幕（没有就把声音一分钟一段转成文字）、
  弹幕最热闹的几段、热评，整理成要点（带时间）；之后几小时里聊到就能接（“第 3 分钟那段笑死”）；发给她看的（@她 / 回她）看完说两句感想；
  也记进“她知道的事”（`watch_videos`，`net.asr`）
- **群友在哪、那边天气**（`aigroup/net/where.py`，表 `qq_where`）：有人说“我在珠海出差”“到成都了”“回老家了”她就记下
  （先查一遍是不是真的城市，查到同名的村子不算），整理印象时也会顺带记；分“住的地方”和“这几天在的地方”（出差旅游到日子就忘）。
  “群里的人”里会写“他这几天在珠海出差，那边今天多云 22~27°C，明天中雨”；他在外地、那边要下大雨 / 下雪 / 太热太冷 / 刮大风，
  她会提醒一句（每个群每天最多一次，`weather`、`weather_care`）。小屋“她的日子”里能看、能改、能删
- 网页脚本加了语法检查

## 4.3.0
- **群友生日和节日**：在小屋“她的日子”里给群友填生日（月-日），那天上午她会在那个人常待的群里祝一句；节日也会应个景（节气只算冬至）；“接下来一个月”能看到（`celebrate`）
- **每周评测**（`aigroup/eval/weekly.py`）：每周一挑她最近一周说的 10 句，让大模型按扣分制找毛病打分，记下每周的分数和最常见的毛病；
  人设文件改过（启动时自动记版本），就挑 8 段真实聊天，用上一版和这一版人设各生成一次，盲比哪句更像群里的真朋友。
  小屋“性格开关”页下面能看到，也能点“现在评一次”“和上一版人设比一比”；命令行 `python run.py replay --compare 8`（`weekly_eval`）
- **每天花费上限**（`llm.budget`，`aigroup/llm/budget.py`，和 ai-life 11.3 同一套）：到了上限后台的活和分享、画图先停，聊天再多一成也停，第二天恢复
- 去掉 QQ 自带 AI 语音（`ai_voice_chance`）
- 小屋“性格开关”里补上 4.2 的那组开关

## 4.2.0 — 人物慢慢长
- **和每个人越来越熟**：熟悉度变成慢慢涨的分数（找她说话最算数，一起在群里聊也算一点；两周没来往慢慢淡），五档：刚认识 / 混熟了 / 挺熟 / 很熟 / 老朋友，
  每一档怎么相处写进“群里的人”（越熟越敢损、越会主动关心）；小屋“她的日子”里能看到每个人的进度和最近谁变熟了（`chat/grow.py`，表 `qq_closeness`）
- **说出口的喜好不改口**：她在群里亲口说过的喜好和看法（讨厌香菜、支持哪个队）和整理印象同一次调用里顺带记下，第一次说的就定下来，以后每次都带上；小屋里能删、能改
- **每月整理“我是怎样的人”**：每周一的回想攒下来，每月初沉淀成几句稳定的性格和口味（不能和人设冲突），放进提示词
- **记住约好的事**：群里约了时间的事（周四开黑、明天考试、下周二面试）整理印象时顺带记下；大家一起的活动到点前喊一声，某个人自己的事过后问一句结果；每个群每天最多 3 次
- **被纠正了就改**：有人回她“不对 / 其实是……”时，后台对一下她记的知识，对的就改（标成“被纠正过”）
- **偶尔分享刷到的东西**：每个群每天最多一次，挑群里不忙的时候，按大家的兴趣刷一下新消息，觉得有意思就随手转一句；有时候是一张自己的日常照片
  （要在 `llm.routes.image` 配画图接口，比如硅基流动的 Z-Image-Turbo；每天最多 1 张，不拍脸）
- **小屋**：新的“她的日子”页（这一周的她、她是怎样的人、喜好、和大家多熟、记着的约定、分享过的、最近知道的事，都能改）；
  “性格开关 / 大模型 / 日志”收进右边的“管理”；“学到的”知识能改、能手动教她一件事；放在服务器上时左上角有回小屋首页的按钮
- 新开关：`monthly_self`、`plans`、`plans_per_day`、`fix_knowledge`、`share_per_day`、`share_chance`、`photo_share_chance`、`photo_per_day`

## 4.0.0 — 能上网了
- **读群友发的链接**：网址、B 站 / 公众号等分享卡片点开看（标题、简介、正文开头），写在那条消息后面，她能接着聊内容，不用假装看过（`aigroup/net/links.py`，从 ai-life 搬过来的：只访问公网地址、每一跳都检查）
- **不知道的先搜一搜**：有人问“××是什么 / 谁 / 讲了什么 / 怎么样 / 什么时候上线 / 比分”这类她可能不知道的事，后台模型先判断要不要查、查什么，
  要查就搜（默认依次试百度、360、搜狗、必应，不用 Key，结果对不上查询词就换下一个；config 的 `net.zhipu_key` 填了、有余额就先用智谱的搜索接口），把几条摘要给她看，她像自己刚看到的那样随口说重点（`aigroup/net/search.py`）
- **记下来、慢慢长出来**：搜到的、读到的要点整理成一条“知道的事”（话题、关键词、一两句话），以后聊到关键词就想起来；常被想起的变成她“最近在了解、感兴趣的东西”，
  影响她的谈资和口味（`aigroup/net/knowledge.py`，表 `qq_knowledge`）。小屋“学到的”页能看到、能删；“性格开关”里多了“联网”一组
- **`python run.py seed 文件.yaml`**（从微信版搬过来，按群号、QQ 号写）：把事先写好的群笔记、群规矩、群梗词条、每个人的别名和画像灌给她
- `persona/local_*.md` 不进 git（放写了真名的人设）
