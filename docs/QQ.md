# QQ：一对一的她 + 独立的群聊角色

这里有两件事，互不相干：

- **一对一的她上 QQ**（本文前半部分）：可以和 Telegram 同时用，也可以只用 QQ。
- **独立的群聊角色**（本文最后一节“第二个角色”）：另一个人设、另一个 QQ 小号、另一份数据，专门待在群里。

## 一对一的她

她可以同时在 Telegram 和 QQ 上：

- **QQ 私聊**：和 Telegram 是同一个她、同一份聊天记录、同一份记忆和心情。你最后在哪边说话，她就在哪边回你；主动找你也发到那一边。QQ 没连上时自动退回 Telegram。
- **QQ 群聊**：她作为你们的朋友待在群里。被 @、被回复、被叫名字一定会回；其他时候偶尔插一句。对群友是“关系很好的朋友”，对你还是平时的样子。

## 先知道这几件事

1. **QQ 没有给个人用的机器人接口**，这里用的是 NapCat（非官方协议端）登录一个 QQ 小号。**有封号风险，一定用小号，别用主号。**
2. NapCat 和 ai-life 都跑在你这台电脑上。电脑关机时她在 QQ 上也不在线（开机后离线补帧照常工作）。
3. 群聊消息**单独存放**，不进你们俩的聊天记录，不参与整理记忆、写日记。她在群里**不会去翻关于你的记忆**，所以你私下跟她说的事不会在群里说漏。
4. 群聊会多花不少模型调用。`glm-4.7-flash` 本来就常被限流（1305），群很活跃的话建议先把 `qq.group.interject_chance` 调低。

## 第一步：一键配置（Windows）

双击项目文件夹里的 **`qq_setup.bat`**（第一次用 `install.bat` 时在配置向导里选 QQ 也一样）。它会：

1. **找 NapCat**：程序目录下的 `napcat/`、或者你以前自己装的（桌面、下载、各个盘的根目录）。都没有就**自动下载**官方的
   `NapCat.Shell.Windows.Node.zip`（约 120 MB，自带 QQ 内核，**不用另外装 QQ**）解压到 `napcat/`。
   GitHub 慢时依次换几个公共加速地址；全失败就提示你手动下载，把 zip 放进项目文件夹再运行一次。
2. **配好 WebSocket**：在 NapCat 的配置里写好 `127.0.0.1:3001`、消息格式 array、随机 token（不用打开 WebUI 手动建）。
3. **启动 NapCat 并登录**：第一次会弹出二维码，**用她的小号**在手机 QQ 上扫码确认。
   扫码前先退出电脑上已登录的这个号的 QQ。⚠️ NapCat 是非官方协议端，**有封号风险，一定用小号**。
4. **打开自动登录**：把小号写进 NapCat 的自动登录设置，以后带 `-q 号码` 启动，**不用再扫码**。
5. **选出你自己**：列出小号的好友，输入编号选你自己的 QQ；问你 Telegram 还要不要。
6. **写好 `config.yaml`** 的 `qq:` 一节（先备份到 `data/backup/`，token 放进 `.env`），写完重新读一遍核对，不对就原样恢复。

<summary>手动装 NapCat / Linux（Docker）</summary>

1. 打开 NapCat 的官方发布页：<https://github.com/NapNeko/NapCatQQ/releases>。Windows 下载 `NapCat.Shell.Windows.Node.zip`，
   Linux 用它的 Docker 版。只从官方 GitHub 下载。
2. 启动后用小号扫码登录；浏览器打开 WebUI（默认 `http://127.0.0.1:6099`，token 在窗口里），
   **网络配置** → 新建 **WebSocket 服务器**：主机 `127.0.0.1`、端口 `3001`、消息格式 **array**、设一个 token，启用并保存。
3. 运行 `python run.py qqsetup --manual`：只读现成的 NapCat 配置，选你的 QQ，写好 `config.yaml`。

`config.yaml` 里的 `qq:` 一节长这样（字段说明见 `config.example.yaml`）：

```yaml
qq:
  enabled: true
  ws_url: "ws://127.0.0.1:3001"
  access_token: "${QQ_ACCESS_TOKEN}"   # .env 里写 QQ_ACCESS_TOKEN=NapCat 里那串 token
  owner_id: 你自己的QQ号
  napcat_dir: "C:/ai-life/napcat"      # start.bat 顺便启动 NapCat 用
  napcat_qq: 她的小号                    # 快速登录用，有了它就不用每次扫码
```

## 第二步：启动和测试

1. **加好友**：用你自己的 QQ 加她的小号为好友（程序开着时会自动同意）。**这一步必须做**：QQ 不允许给非好友主动发私聊，
   不加好友的话她只能回你，早安、想你、提醒这些主动消息都发不出去。`qq_setup` 和 `/diag` 都会提示还不是好友。
2. 双击 `start.bat`。日志里看到 `QQ 已连上 NapCat` 和 `QQ 账号：…` 就通了。
3. 用你的 QQ 给她发消息。手机上看小屋：给她发 `/小屋`，点她回的链接。

以后只要双击 `start.bat`：NapCat 没在运行的话，它会顺便把 NapCat 启动（任务栏里最小化的窗口），
带 `-q 小号` 快速登录，不用再扫码。只有 QQ 那边要求重新验证（换了密码、在手机上被踢、很久没登录）时才要再扫，
那时二维码图片会自动弹出来。
NapCat 已经开着就不会再开第二个。不想让它自动开：`config.yaml` 的 `qq:` 里写 `napcat_autostart: false`。

## QQ 私聊里的她

| | Telegram | QQ 私聊 |
|---|---|---|
| 文字、分条、打字停顿 | ✓ | ✓，你那边会显示“对方正在输入…” |
| 发照片 | ✓ | ✓ |
| 表情 | 贴纸包 | 先用**从你那学来的表情包**，没有合适的就发 QQ 小黄脸 |
| 打错字 | 发出去再改 | QQ 改不了已发的消息，所以像真人一样补一句“*正确的字” |
| 撤回 | ✓ | ✓ |
| 给消息点表情 | ✓ | ✗（QQ 私聊没有，她在 QQ 上也不会想这么做） |
| 认你发的图片 | ✓ | ✓ |
| 认你发的表情包 | 贴纸 | ✓ 看懂是什么情绪，存下来自己以后也用 |
| 你戳她 | — | ✓ 她会回应，有时戳回去（`poke_back`） |
| 你撤回消息 | — | ✓ 她已经看到了，可能逗你一句，也可能装没看见 |
| 合并转发的聊天记录 | — | ✓ 会读里面的内容 |
| 分享卡片（B 站、小程序、链接） | 链接 | ✓ 认出标题和链接，能点开读的就读完再回 |
| 引用很早以前的消息 | ✓ | ✓（去 NapCat 取原文） |
| 个性签名 | — | ✓ 每天跟着她的安排和心情变（`signature`） |
| 命令 | ✓ | ✓（也能用中文：/日记 /记忆 /心情 /小屋 /帮助）；要点按钮的 /game 除外 |
| 小屋 | 菜单按钮 | /小屋 给一个浏览器链接（12 小时有效）；页面上的提示会按你用的是 QQ 还是 Telegram 变 |
| 告诉她“这句不对味” | 给消息点 👎 | 引用她那句话，回一个 👎（进小屋的“她会避开的说法”） |
| 每周来信、纪念册、时间胶囊、提醒 | ✓ | ✓（发到你最后说话的那边） |
| 关程序时道别 | ✓ | ✓ |

发送失败（NapCat 偶尔超时、正在重连）会自动等一下再试一次。`/diag` 里有一行 QQ 状态：连没连上、是不是好友、你上次在 QQ 说话是多久前。

## 一对一的她进群（可选）

`qq.groups` 里写上群号，一对一的她也会进群。这时你在群里还是她的“哥哥”，你们私下的事她不在群里说。
如果你想要的是**另一个人**待在群里，用下面的“第二个角色”，`qq.groups` 留空。

## 群里的她（两种都适用）

- 群友的印象存在 `qq_people` 表里，每攒 40 条群消息自动整理一次（用 `memory` 路线的模型，后台慢慢做）。
- 免打扰时段（`proactive.quiet_hours`）里她只回叫到她的消息。
- 有人在群里让她“换角色 / 忽略设定”，她会当玩笑吐槽，不照做。
- 发出去的消息一律是消息段，不拼 CQ 码：她就算写出 `[CQ:at,qq=all]` 也只是一串文字，不会真的 @全体。

## 出问题时

- 日志一直说 `连不上 NapCat`：NapCat 没开，或者 WebSocket 服务器没启用 / 端口不是 3001。
- 她回你，但从来不主动找你：她的小号还不是你的好友（看 `/diag` 的 QQ 那行）。
- 你那边看不到“正在输入”、戳不回去、签名没变：NapCat 版本太旧，没有这几个扩展接口，更新 NapCat；聊天本身不受影响。
- 连上了但私聊不回：`qq.owner_id` 填的不是你自己的号（日志会提示“不是 qq.owner_id，不理”）。
- 群里不说话：群号没写进 `qq.groups`；或者没人叫她、插话骰子没中（正常）。

## 第二个角色：独立的群聊角色

另一个人设、另一个 QQ 小号、另一份数据（记忆、心情、对群友的印象），和一对一的她互不相干。
只跑群聊：不启动 Telegram、私聊、桌宠、小屋、电脑感知。她还是有自己每天的安排，群里聊起来前后一致。
你在群里对她来说就是一个老朋友（`relation: friend`）。

1. **再登录一个 QQ 小号**。同一台电脑上要让 NapCat 同时登录两个号（“多开”），具体做法照 NapCat 官方文档里多开的说明来，
   不同版本做法不一样。第二个号的 WebSocket 服务器开在 **3002** 端口（别和一对一的 3001 撞）；
   如果两份 NapCat 的 WebUI 端口冲突，把第二份的改掉。
2. 把 `config.group.example.yaml` 复制成 `config.group.yaml`，改好打 ★ 的地方：人设、端口、你的 QQ 号、群号。
   它会先继承你 `config.yaml` 里的大模型 key 和代理，不用再填一遍。
3. 人设：`persona/xiaoman.md` 是给你起草的“小满”，照着改，或者换成你自己写的。
4. 双击 **`start_group.bat`**。它和 `start.bat` 是两个窗口，各跑各的，可以同时开。
5. 日志在 `instances/qq-group/data/logs/` 里。

想再加一个群聊角色（另一个群、另一个人设）：再复制一份配置（比如 `config.group2.yaml`），
改 `instance_root`、`persona_file`、`ws_url`，再登录一个小号，然后在命令行里运行 `start_group.bat config.group2.yaml`。

群聊角色特有的：

- **冒泡**：群里安静超过 3 小时（`idle_hours`），她可能自己说一句，分享她今天的事或者接着之前的话题。
  两次冒泡至少隔 6 小时，只在 `active_hours` 里、免打扰时段外；如果群里最后一句就是她说的，她不会再自言自语。
- **对你也会形成印象**：friend 模式下你和别的群友一样，她会慢慢记住你的样子（`owner_note` 是一开始的印象）。
